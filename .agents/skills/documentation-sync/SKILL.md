---

# Documentation sync

1. Identify documentation directly affected by the change.
2. Update commands/examples to match actual repository behavior.
3. Keep architecture docs about stable structure, not transient implementation detail.
4. Remove stale instructions instead of layering contradictory notes.
5. Prefer links/references over copying the same facts into many files.
6. Do not update docs merely because a file was touched.
