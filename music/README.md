# Фоновая музыка для Shorts

Эта папка используется для фоновой музыки при финальной сборке Shorts.
Управлять музыкой можно в интерфейсе приложения — раздел «Фоновая музыка»
на экране настроек серии (включение, громкость, выбор трека, открытие папки).
Настройки из интерфейса сохраняются в `data/settings/music.json`.

`config.json` в этой папке — шаблон значений по умолчанию. Он применяется,
если настройки ещё не сохранялись через интерфейс.

## Куда класть музыку

Положите файлы `mp3` / `wav` прямо в эту папку (`music/`):

```
music/
├── config.json
├── README.md
└── A_Distant_Call.mp3   ← ваш трек
```

Если треков несколько, по умолчанию выбирается **случайный** трек.
В интерфейсе можно закрепить конкретный трек (поле «Трек») или нажать
«Выбрать случайный».

## Поддерживаемые форматы

- `.mp3`
- `.wav`
- `.m4a`
- `.aac`
- `.flac`
- `.ogg`
- `.opus`

Остальные файлы (например, `.txt`, `.jpg`) игнорируются.

## Как включить / выключить музыку

В интерфейсе: откройте настройки серии → раздел «Фоновая музыка» и включите
или выключите переключатель. Изменения сохраняются автоматически.

Вручную: отредактируйте `music/config.json` (шаблон по умолчанию):

```json
{
  "music": {
    "enabled": true,
    "volume": 0.15,
    "fade_in": true,
    "fade_out": true
  }
}
```

- `enabled: false` — музыка полностью отключена.
- `enabled: true` — музыка добавляется поверх оригинального звука видео.

Если `enabled: true`, но папка пустая — сборка продолжается без музыки,
в лог пишется, что музыка пропущена.

## Громкость

`volume` — громкость музыки относительно голоса:

- `0.15` = 15% громкости (значение по умолчанию);
- `1.0` = 100%.

Голос видео не меняется. Музыка подмешивается тише голоса, а лимитер
(`alimiter`) защищает итоговый звук от перегрузки/клиппинга.

## fade in / fade out

- `fade_in: true` — плавное появление музыки в начале;
- `fade_out: true` — плавное затухание в конце.

Музыка автоматически обрезается или зацикливается до длины Shorts.
