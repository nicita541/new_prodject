## Что уже изменено

- Ограничение $0.10 на попытку убрано: EPISODE_BUDGET=None. Учёт расходов, защита от неопределённого списания и повторения отклонённых запросов сохранены. Нельзя обнулять историю расходов.
- app/provider_balance.py хранит наблюдения публичного API /user/balance отдельно от платного ledger. UI разделяет реальный баланс аккаунта и консервативную оценку по токенам. API баланса не предоставляет расход по отдельному ключу; пользователь отказался от входа в кабинет. Не приписывать разницу баланса конкретному ключу.
- app/production.py заменяет изолированное определение титров анализом последовательности с исходным визуальным контекстом. Кадры физически расположены по времени исходника; раньше контекст сверху и проверяемые кадры снизу вводили модель в заблуждение о порядке событий.
- Текстовые и визуальные подтверждения отделены от важности сцены. Короткая речь персонажа, причинные действия и тихие значимые сцены защищены. Неуверенный результат не должен превращаться в удаление.
- В production используется DeepSeek thinking с reasoning_effort=low, отдельным профилем/кэшем. Последний реальный пакет из 8 единиц исчерпал 8192 выходных токена. Текущая версия уменьшает пакет до 4 единиц, ограничивает количество положительных якорей и длину объяснений; соседние с титрами единицы с уверенной речью не отправляются на удаление. - app/titles.py выполняет один предварительный экран кандидатов на событие, затем проверяет фактические единицы. app/pacing.py дробит немые пробелы по настоящим границам кадров, не создаёт мельчайшие фрагменты <0.75 с, сохраняет речь и контекст. Ошибочный свидетель повтора блокирует удаление этой единицы, не отменяя другие подтверждённые решения. Отмена больше не проглатывается как OSError.
