# Структура кода и границы очистки

Проверка 11 октября 2026: собственные Python-модули `app/`, точки запуска и их импорты. Модели, runtime dependencies и пользовательские видео не анализируются как собственный код.

## Достижимость модулей

AST-граф импортов от `server`, `launcher`, `worker`, `inference` достигает **66 из 67 файлов app**. Оставшийся `__init__.py` — файл самого пакета, который Python загружает при импорте. На этом уровне нет отдельно лежащего очевидно заброшенного app-модуля, который можно уверенно удалить только потому, что он старый.

Это не доказательство использования каждой функции или исполнения каждой optional ветви: AST учитывает и импорты внутри ветвлений, а динамические обращения требуют отдельной проверки. Некоторые функции `analysis.py` экспортируются для совместимости и используются другими модулями/тестами, даже если внутри самого файла не вызываются. Автоматическое удаление по одному списку unused imports здесь опасно.

Удалены три подтверждённо неиспользуемых импорта в операционной части: `Decimal` в `jobs.py`, `json` и `math` в `studio_render.py`. Проверка прямых внешних обращений в app/scripts/tests их не обнаружила. Модельные/семантические модули во время измерений не переписываются: их исходный код участвует в cache identity и проверке стабильности наблюдателя.

## Результат очистки 13 октября 2026

Осталась одна Studio Edition. React, legacy, reference HTML и их отдельные fixtures/checks удалены. Продукт больше не содержит seed-каталог, вымышленный план, встроенный demo MP4, WebAudio-имитацию или mock API. Пустое начальное состояние заполняется реальным API. Рабочий JavaScript Studio и bridge отформатированы для чтения и поиска функций. Сборка использует native Node, без Vite/React/TypeScript; jsdom нужен только для изолированных проверок.

`analysis_result`, `editorial_pipeline`, `quality_recovery` выделены из прежних смешанных владельцев. `final_quality` проверяет, `quality_recovery` исправляет, `pipeline` ограничивает и координирует повторы. `studio_routes` отделяет адреса/статику Studio от server API. Идентичные функции текста/цитат, отмены и hashes используют общие реализации; разные JSON encodings не смешаны. Новые helpers входят в семантические identities.

Исторические размеры/граф выше относятся к аудиту 11 октября. Удаление интерфейсов не доказывает, что каждая оставшаяся optional ветвь исполняется. Изолированные тестовые fixtures остаются в tests, не в продукте. Реальные пользовательские источники, задания, настройки и кэш ответов сохранены. Новые границы и rollback: [ADR 0032](../ai/decisions/0032-studio-only-and-pipeline-ownership.md).

## Безопасная последовательность дальнейшей очистки

Выбрать конкретный недостижимый код → проверить imports, callback/decorators, dynamic обращения и публичный контракт → удалить небольшой фрагмент → выполнить существующие профильные проверки. Изменения семантических модулей отражаются в cache identity; старые дорогие checkpoints нужно сохранить для сравнения. Подробный общий порядок улучшений — в [findings](findings.md).

Проверка также обнаружила и исправила сбой API статуса на повреждённой diagnostic stage: нестроковые значения пропускаются, без изменения job/checkpoints.

## Повторная проверка остатков, 13 октября

Обнаружены и удалены обратные utility-вызовы через analysis, зависимость finishing от server, копии JSON writers, merge/intersection и подготовки cache payload. Новый индекс [зон ответственности](../../app/README.md) связывает функции с владельцами. Удалены неиспользуемые fixed analysis windows/cut-time helper, отдельный simulation planner, дублирующий старый батник просмотра интерфейса, семь недостижимых действий старого review и 160 rv-селекторов (61 класс). Форматированные CSS/JS остаются ресурсами единственного Studio.

Это подтверждённая очистка проверенных путей, а не доказательство отсутствия любого мёртвого кода: условные provider/recovery ветви требуют своих контрактов. Похожие предметные validators с разными правилами нормализации не объединяются только по названию. Общие алгоритмы имеют единственную реализацию, различающиеся форматы JSON задаются параметрами. Модульные границы закреплены тестом; реальные данные не удалялись. [ADR 0033](../ai/decisions/0033-direct-module-ownership.md).
