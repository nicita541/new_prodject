# Independent analysis checks share bounded Antigravity transport

The automatic provider uses one coordinator and at most four producers to send independent native checks together. This now covers titles, closing novelty, source roles, OP/ED production sequences and ending windows, alongside existing scene refinement, global visual checks and selection adjudication. The official runner remains bounded to two CLI children; Windows command length and image capacity can split a group further.

Closing and role reviews receive the immutable full episode and select their event explicitly. Closing stays ordered until an ending anchor is already established; otherwise an accepted omission can change the anchor for subsequent events. Overlapping legacy events and production groups sharing exactly the same context/cache files stay serial. Production clusters return review deltas; their overlapping contexts are reduced in original order and exclusions applied as a union once. Ending windows retain original context and confirmations; duplicate windows share proof, overlapping proposals keep the first accepted ending, and planner recovery runs once after merging. Native schemas, source provenance, independent confirmations and conservative failure behavior remain authoritative.

Pacing and silent-sequence retention remain ordered because repeat witnesses depend on accepted earlier decisions. Automatic cloud pacing accepts up to sixteen rows on two pages of eight, with complete per-row validation and last-copy protection. Story structure uses eight whole units with an 8500 output budget; dialogue retains twelve. Failed text groups still split locally; accepted groups and story memory survive.

Manual/local providers retain their original limits. The existing per-job batching opt-out and bounded text configuration provide rollback without a data migration. Unchanged native event requests and proofs keep their cache keys; source-vision semantic components are not edited. Derived story/pacing/planning identities change where their executing code changes, so no old derived result is relabeled as newly verified.

Verification compares serial and accelerated native prompts, schemas, source windows, ordered decisions, signed proofs, warm resumes and cancellation. Transport tests establish fewer coordinator submissions; actual CLI groups and wall time depend on full command size, image counts, model output and service limits. This does not promise a fixed speedup or skip a quality gate.
