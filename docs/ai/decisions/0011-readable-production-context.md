# Readable source chronology for production-sequence checks

Independent motion plausibility is insufficient to distinguish character animation in an OP/ED from a new episode event. Production checks compare bounded source units with original nearby production-anchor frames; true narrative, dialogue and uncertain evidence remain protected. The context and target frames are ordered physically by source timestamp, even when reference frames follow the target.

DeepSeek Flash automatically resizes each image to a bounded pixel/token area. A tall collage loses fine credit text and distinctions between shots. The adapter now accepts one Path or an ordered list of 1–8 workspace image Paths. Production sends chronological pages of up to 12 tiles; other stages keep the existing single-image interface. Each page counts independently in the conservative 1024-token image reservation and in content-addressed cache identity. All paths and sizes are validated before reserving or sending. No remote image URLs or new providers are introduced.

Two real thinking-low batches exhausted 8192 output tokens without final JSON, including a four-unit batch. Production no longer forces paid reasoning; it retains the supplied provider mode with compact four-unit decisions. The explicit reasoning adapter remains available for diagnostics, separately cached, but is not used by this pipeline stage. Rejected requests remain accounted and blocked from replay.

EDGE_VERSION=10 invalidates old derived credit decisions. Existing factual preparation, compatible story decisions, successful paid response caches and previous exports are preserved. Local/hybrid sessions without page support keep the single chronological collage. Rollback can restore the prior page layout/profile; it must never reset costs, replay guards or user projects.

Validation: real source chronology, legible bounded page area, no forced cloud reasoning, full source-unit mapping, every-page cache identity, page-count/path checks and per-page reserves have regression coverage. Actual editorial quality still requires the three-source comparison in .agent/plans/three-source-editorial-regression.md.

Provider contract: https://api-docs.deepseek.com/guides/vision/ (checked 2026-10-04). Pro currently accepts text only; it is not substituted for visual analysis.
