# ADR-0063: Review introduced source gaps with their omitted original observations

Status: implemented; controlled repair verified, ordinary-route semantic false positive remains unresolved.

## Context

The ordinary50.13s test export passed native and blind checks but removed source
60.34–64.79s. Output-only review flagged its jump at30.8s. Original source images
then confirmed that the omitted material contains the rise and actual fall,
while the edit retains the request and already-fallen aftermath. This is a
reproducible causal/action defect. Frames from the omitted interval were available
to the native reviewer, but the contract required proofs only for retained edges
and opening/development/ending, which could all be speech proofs.

## Decision

New whole-candidate jobs carry versioned source_join_policy in analysis, case,
qualification identity and scoped compiler inputs. Legacy cases without the
policy retain their historical contract; no old raw judgement is rewritten.

In the existing native source review request, explicitly enumerate each positive
gap between actual audible cuts. Bind both retained-edge anchors and the omitted
original frame indices/unit IDs from actual decoded PTS, not requested times.
Observe beginning/middle/end of each gap in addition to existing shot/motion
samples so a large physical unit cannot leave a short gap wholly unobserved.

Positive approval requires one grounded join row per actual gap, both exact
retained anchors, own omitted image citations and factual evidence. The model
classifies incidental/redundant versus required cause/response/action/unresolved.
Required or uncertain omissions cannot be safe_to_omit or authorize export.
Negative reviews can leave joins empty; invalid frame ownership is a contract
error. Missing observed gap evidence cannot be replaced by a fabricated proof.

This adds no model pass, agent role, confidence threshold or all-motion retention
rule. The current output allowance stays unchanged. Unknown/failed dispatch
protection and exact positive/negative question reuse remain. The cut-only viewer
still receives no omitted context or native judgement.

## Validation and limits

Implement source-policy propagation, pure geometry/ownership checks, native payload
and gap observations, then focused regressions. Recheck the SAME defective
automatic proposal with the new source contract, without a new proposer or a
supplied old verdict, to establish whether the newly explicit task catches it.
Keep original and new outcomes separately. Do not rerun unchanged paid questions
until one approves or silently patch an already approved timeline.

A bounded proof-driven restoration, if needed, is separate work: add only observed
required units inside original gaps and rerun both normal checks. It must not
expand outer story bounds, restore all silent footage, repeat indefinitely or
publish changed geometry using the old approval. Audio/corpus/editorial acceptance
remains mandatory beyond these mechanism checks.

## Failed v1 and factual-change v2

The first two real v1 regressions still approved the same defective edit. Their
join evidence explicitly admitted that the fall was omitted but classified it
incidental because pain/examination remained. Thus explicit gap citations and
stronger instructions alone did not establish correct action preservation.
An isolated reasoning-low experiment exhausted8192generation tokens without valid
JSON; it is not enabled in the ordinary factory. Its failed result is retained.

New cases now use policy version2, while exact version1 and absent-policy records
remain readable. Each v2 join additionally describes a factual change.kind and
owned before/after state/image pair, separately from its safe/classification
opinion. Categories distinguish minor motion/speech/no change from physical_event,
object_change, reveal, scene_change and unresolved. Required state observations
must use actual ordered distinct source pixels inside the omitted interval.

A substantial omitted event cannot approve merely because safe_to_omit is true.
It needs a factual retained_witness of the SAME event with ordered distinct
images inside ONE uninterrupted retained cut. The two retained edges across the
gap, later speech and aftermath cannot serve as that witness. Without it the
pure compiler gate returns needs_review. Unresolved/insufficient observations
also cannot approve. Neutral motion/gestures remain eligible for omission; this
is not a blanket retention rule. The model still owns factual interpretation, so
the actual defective edit and an intact positive control must test this policy
before any claim of semantic reliability.

The first real v2 regression then rejected the SAME defective edit in18.584s
at source review, without a new proposer, blind call or publication. Its own
factual row identified standing→fallen physical_event without a retained witness.
This is one-source evidence for the combined task/contract, not an isolated
causal comparison or broad reliability result. Unchanged none/speech_only pairs
may have identical pixels at distinct source PTS; claims of motion/substantial
change still require different pixels. Do not force static waiting to remain
because its truthful observations are identical.

A single grounded restoration is integrated as an alternative to the
existing single blind trim. Add only continuous own catalog-unit runs between
verified omitted before/after observations, preserve prior semantic selection,
bind the old review to its exact old timeline, and never extend outer story
bounds. After actual audio geometry, the new edit must preserve all prior footage,
add only inside original actual gaps and meet maximum duration. Preserve history
and run fresh source plus cut-only checks. The same candidate cannot then trim
or restore again. Unresolved/invalid/unbound observations supply no restoration.

Only the immediate catalog neighbors of a proved restored run may close its
whole-unit owners when they contain an old audible edge of that same gap and
were already partly retained. This closure cannot chain, cross another gap or
extend outer semantic bounds. The actual-cut superset guard remains authoritative:
the first real attempt correctly stopped without inference after remeasurement
would have lost 0.17s of an old audio handle.

With that owner closure, the same automatically derived repair retained the
complete old edit and added only its four proved gaps. Fresh source and cut-only
reviews approved the resulting continuous source interval21.86–83.92s in16.875s,
using two remote requests/39640 reported tokens. The exact warm repeat took3.293s
with remote transport and local startup forbidden. Deterministic compilation
preserved the approved geometry; the62.06s NVENC export passed full decoding.
Artifacts: temp/source-join-restore-6f507c01ab1e. This is a controlled workflow
regression using an existing genuine negative review, not a fresh discovery or
corpus quality claim. Independent output review, listening and full-route
validation remain separate requirements.

## Ordinary-route counterexample

The ordinary full-route resume under v2 took101.852s/9new remote starts with stable
app code. It still approved the same defective50.13s edit, while another candidate
had a preserved model-output technical failure. Exact warm reuse took5.688s with
transport/startup forbidden; it preserved both outcomes, not editorial success.

Read-only comparison found no missing source image or index/transport mismatch.
The ordinary packet had124images including all108control images and16extras
outside the fall gap; its actual timeline, physical units and fall observations
were identical. The positive response described the unchanged standing male and
ignored the visible girl rising and falling. Thus v2 cannot establish truth from
schema validity alone; the controlled negative did not generalize even here.

An isolated gap-focused presentation experiment kept the same124observations and
actual edit but separated retained cuts/removed joins/outer context into16pages,
using6panels for removed regions. It did not fix the factual interpretation:
both raw answers still described all gaps as neutral. They also failed schema
validation (misnested retained_witness, then absent speech-proof motion); the
bounded correction is retained as a second transport, not a new semantic success.
Total26.450s/2remote starts/51873reported tokens, no blind call/publication.
The experimental layout code/tests were archived with that job and removed from
production: it increased input cost without demonstrated benefit. Artifacts:
temp/gap-focused-source-0376957d6224. Further paid repetitions of the same question
or speculative prompt growth are not a repair.

## Explicit paired-image navigation

A bounded six-original-image capability diagnostic misassigned changes to pairs:
it described the standing-to-fallen pair under a different pair number. With the
same observations/schema on three explicitly labelled left-before/right-after
images, the narrow task correctly distinguished that physical change from a
static pose control. This demonstrates a representation/association issue on
these examples, not an isolated cause of all native failures.

The existing native request now prepends one labelled endpoint-pair image per
observed omitted join. IDs and actual source PTS stay original; the prompt maps
each image to its two omitted frames. All ordinary source pages still follow:
the overview cannot establish that nothing happened between endpoints. Native
review must consider every changing visible subject, including one beside an
unchanged foreground character. Proposal/cut-only inputs receive no such omitted
context. Count actual total pages before dispatch, without dropping evidence.

With those overviews, the SAME ordinary failed edit and124observations were
rejected in19.225s/1remote request/26368reported tokens, with an explicit omitted
fall and no blind call (temp/join-pair-source-6244c0b4baf3). A single grounded
restoration then added only60.75–64.62s, preserving every old cut, but its fresh
source check remained needs_review: it produced contradictory/incorrect claims
about the other gaps. No second repair or blind call/publication occurred.
Artifacts: temp/join-pair-restore-9a88405c482f,16.093s. The overview mechanism
passes ownership/cache/capacity tests and independent code review; semantic
reliability and ordinary-route acceptance remain unproven. Repeating changed
prompts indefinitely is not a substitute for simplifying overlapping model work.
