# ADR-0027: Штатная остановка только свободного Studio

## Status
Accepted, 2026-10-11.

## Context
Запуск уже проверяет идентичность workspace, backend и интерфейса на порту 8765. Для остановки требовалась исходная консоль с Ctrl+C. Команда `taskkill` по имени Python могла бы завершить посторонние приложения; завершение занятого KADR могло бы прервать анализ или экспорт.

## Decision
`POST /api/studio/shutdown` принимает строгое тело `{"identity": <server_identity>}` и использует существующие ограничения Host/Origin/Content-Type. Отличающаяся идентичность, отсутствие callback Uvicorn, активный анализ и finishing-задачи дают 409 без остановки.

Проверка свободного менеджера и установка `shutdown_requested` выполняются под `manager.mutex`. Запуск анализа и finishing проверяют этот флаг под тем же mutex. Middleware отклоняет новые изменяющие запросы после установки флага. Callback ставит `uvicorn.Server.should_exit = True`; при ошибке callback флаг сбрасывается. OS lock освобождается только штатным `JobManager.close()` в FastAPI lifespan, вместе с принадлежащими менеджеру ресурсами.

`python -m app.launcher --stop` проверяет идентичность, отправляет запрос и ждёт исчезновения этого экземпляра до 15 секунд. `остановить_Кадр.bat` вызывает этот путь. Команды убийства PID не используются. Ctrl+C сохраняется как путь остановки исходной консоли, включая прерывание обработки с возможностью продолжения.

## Alternatives considered
- Ctrl+C без отдельного BAT: простой и безопасный для выбранной консоли, но требует найти окно сервера.
- Поиск PID на порту и taskkill: требует отдельной проверки принадлежности процесса; прекращает активную работу и не гарантирует lifespan cleanup.
- Автоматическая отмена перед остановкой: меняет пользовательское намерение и может потерять текущий прогресс; явная отмена остаётся отдельным действием.

## Consequences
Штатный stop понятен и не вмешивается в занятые задания. Он работает для серверов, запущенных через `app.server.main`/обычный launcher; сторонний запуск `uvicorn app.server:app` без callback должен быть остановлен из исходной консоли. Нет изменения файлового формата или миграции. Текущие HTTP запросы могут завершиться до выхода Uvicorn; новый анализ/экспорт после флага запрещён.

## Revisit when
Появятся очередь нескольких серий, запуск как Windows service или отмена finishing-экспорта. Тогда нужно явно определить graceful-drain и принудительную остановку, не смешивая их с текущим idle-only контрактом.

## Validation
`tests/test_studio_shutdown.py` проверяет identity/schema/origin, занятость, отсутствие callback, rollback, запрет новых задач, callback Uvicorn и удержание OS lock до конца lifespan. `tests/test_launcher.py` проверяет CLI stop/refusal/timeout и готовность запуска. Реальный start/reuse/stop относится к общей проверке аудитора и записывается отдельно в `docs/audit/operations.md`.
