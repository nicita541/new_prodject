# Evidence-specific selection and unresolved planning gate

Production video supplies no named semantic answers. Earlier understanding, ownership and selection are hypotheses whose confidence and purpose differ. Previously, a late error or uncertainty could restore every source unit, and ownership or generic atmosphere hints could re-expand a shortened selection.

Understanding and selection now have distinct confidence fields. Local uncertainty first receives dense CURRENT/neighbor evidence. Targeted adjudication asks disputed factual questions against original frames and exact source ASR. Each actual CURRENT unit has a complete keep/drop decision, a concrete evidence kind and source frame/quote anchors. Both confidence fields and individual unit evidence must reach 0.9 before replacing selection. Long source units are reviewed in bounded views; contradictory partial views remain unresolved. Confirmed source exclusions and control failures keep their authority.

Production source units additionally split at actual ASR onsets and word-safe technical intervals of roughly four seconds. These intervals do not claim semantic boundaries. They allow a long uncut shot's waiting, speech and reaction to receive different source decisions. Targeted boards have at most twelve readable CURRENT frames and two frames per context window, with native decoded PTS and image hashes. The general overview's fixed seventeen supplementary samples are unsuitable for these short context windows: a genuine run exceeded the local model's 8192-token context. Bounded evidence fixes that input cause without increasing model context or replacing failed inference with a selection.

Generic atmosphere, all ASR words, naked action IDs, and endpoints are insufficient fallback evidence. Unresolved failures keep only an intersection of already-selected positive evidence and source-safe intervals. Unexplained empty or broad selections require review. Global visual verification may replace a complete existing unit partition at the same confidence threshold; incomplete page coverage or legacy factual-only output cannot authorize removal. Reaction, emotional pause and comedic payoff need actual visual proof. Neutral scenery and waiting are removable.

Ownership exceptions continue to protect CURRENT story from erroneous broad OP/ED/preview exclusions. Accepted selection adjudication can narrow that material without re-adding the whole ownership range. Empty selection is distinct from missing selection throughout classifiers, pacing, framing and planners.

After global review and again after pacing, the selection gate routes unresolved flags, unknown action ownership, generic atmosphere, low confidence or unexplained retained ranges to targeted source review. It serializes `analysis_unresolved` if evidence remains insufficient. Production analysis includes the gate; both planner modes reject unresolved analysis before timeline work. This milestone does not yet establish canonical state continuity, inferred arcs, or the final pre-render gate; those remain the later milestone's responsibility.

Ending discovery invokes the planner internally, so final selection adjudication precedes that discovery. Unresolved results skip ending discovery and persist their diagnostic gate; they still cannot reach production planning/render. Any new unexplained selection after ending refinement receives another bounded review.

The optional provided-ASR mode is source-hash-bound and validates original word/segment timing without inventing a repair version. Its explicit limitation says the preobtained text was not reverified against audio. Actual quality drivers observe genuine sequential local model requests unchanged. Structural tests using authored semantics or fake adapters prove mechanism invariants only; video quality requires separately recorded actual responses.

Provided ASR accepts only whitelisted speech/time fields and scalar ASR metadata. Unknown nested word/segment fields are rejected, including nested semantic labels. A normalized provided checkpoint can resume only with its exact source-bound provenance and revalidated raw segments. Persisted selection proof records carry source-derived CURRENT frame counts and actual frame times; the final selection gate checks the index domain, unit/view membership, confidence range and exact unit speech quote again. Positive contribution evidence cannot authorize a drop outside a wholly confirmed nonstory exclusion. These checks validate evidence consistency, not the truth of its interpretation.

The adjudicator's nested board/decision cache includes normalized bounded-storyboard code, runtime version and policy before page reuse. Changing extraction geometry cannot reuse the previous selection solely because the old image and metadata hashes remain intact.

Rollback: revert this milestone's implementation and tests, preserving factual source/audio/ASR. Version and normalized source/prompt/policy identities invalidate derived choices. No migration modifies original media or user settings.
