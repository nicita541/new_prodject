# Source-derived structure and mandatory pre-render quality

The source analysis owns semantic evidence. Plans and model confidence cannot erase an established source dependency, invent an action, or justify retaining an uncertain scene. Scene ownership, source-unit selection and story-arc membership are separate decisions; multiple arcs may belong to one scene.

`story_structure_pass` derives canonical entities, states, unit roles, causal relations and arcs from exact accepted source proofs and ordinary ASR. Every reference includes the original event and unit. Canonical synonyms require cited observed mentions; missing state stays unknown. The preferred part count never enters this inference. A closed arc needs a supported source cause/resolution or question/response, with its actual source ranges and inherited proof ownership.

`dialogue_relations` covers every supplied CURRENT unit and infers required exchanges without depending on punctuation. Its exact word/segment ranges and both endpoint owners remain tied to source ASR. Keeping either required endpoint protects the complete exchange and prevents splitting it between parts. Dropping both does not force their restoration.

`source_continuity` compares canonical facts over the actual chosen units. Restoration uses complete known positive units, including omitted units within a retained parent. Bare dependencies and three-second endpoints are insufficient. Unknown or discontinuous gaps route to `continuity_verification`, which inspects original omitted footage and endpoint frames. Its accepted gap/bridge decision carries actual source-frame hashes, checkpoints and exact scoped units. Generic uncertainty cannot authorize a bridge.

`final_quality` runs before planning and again on every fresh or cached plan before rendering. It checks source selection, CURRENT structure/dialogue coverage, source proofs, word boundaries, complete retained actions and exchanges, bridges and continuity. Confirmed source dependencies remain authoritative even if plan metadata is removed. The pipeline permits three automatic recovery passes; unresolved quality raises `analysis_unresolved` before export work and persists the failed audit. Each accepted retained interval receives a source-to-selection evidence chain.

Every actual part ending needs an accepted original arc closing with its inherited CURRENT proof, or an independently verified original ending whose boundary and retained BEFORE/AFTER ASR IDs match. A derived plan's confidence or supported flag and reaching the end of the file have no independent ending authority. Source-role failures route to the responsible source-role pass; retries reopen the failed original ranges even if a later selection is empty. A skipped inspection cannot clear an unresolved failure.

Primary, recovery and global CURRENT views share word-safe technical chunks with at most twelve actual source frames. Neighbor context has two frames. These are inference windows, never new semantic scenes. A full diagnostic overview remains separate; production closing queries the bounded chunk images. The local image-token range is 256–2048 to prevent tiny context views from each consuming 1024 tokens. Code, policy, source, prompt and frame identity changes invalidate derived caches.

Boundary inference describes source evidence before choosing a change scope. Its generated flags distinguish minor motion within an ongoing scene from consequential physical-state changes and location changes. Blinking/speaking motion cannot itself authorize capture, restraint or a new location. Original source-unit editing still evaluates meaningful reactions independently; the boundary decision has no keep/drop authority.

Adjudication has a separate eight-second ordinary ASR discourse window: short visual context must not erase the preceding question when classifying a static-looking spoken response. Adjacent speech informs meaning but cannot supply CURRENT evidence ownership or imply a physical action. Numeric literal policy identities are equal before and after lazy module imports.

Text-only transport omits duplicated audit provenance while full proof remains authoritative for validation and cache identity. Generation binds each CURRENT row and each cited proof to its exact source owner, caps redundant mentions/descriptions, and emits canonical evidence and arcs before dependent assignments and resolution. Nullable/variant/tuple validation is shared by local and configured remote adapters. These are contract constraints, not semantic answers.

Source readiness projects only explicitly named downstream administrative errors out of its check. It preserves the original failure and all source uncertainty/proof constraints. An accepted source selection is reused during a text retry; global readiness remains unresolved until the responsible structure/dialogue passes succeed. Other source failures still require visual adjudication. This prevents a failed text parser from reopening and destabilizing accepted perception.

Rollback is a revert of Stage 4 code and tests. Original media, ASR and user settings are unchanged. Mechanism tests establish these invariants; genuine recorded model runs and rendered raw-video scenarios are required separately for semantic quality. Stage 4 acceptance remains pending until those runs finish.
