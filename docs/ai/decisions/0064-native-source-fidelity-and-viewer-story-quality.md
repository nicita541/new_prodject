# ADR-0064: Separate source fidelity from cut-only story quality

Status: not adopted after failed specificity control; experimental code archived, production v2 retained.

## Context

The native whole-candidate task repeats the viewer's story criteria and three
proofs while also copying/classifying every retained utterance and auditing all
source gaps and actual cut edges. Real ADR0063 trials found schema-valid false
visual claims, including a missed omitted fall and an invented event after a
bounded repair. Correct transport and more labelled pages alone are insufficient.

## Decision

The tested experimental source_join_policy version3 focused the SAME native request on
original-source fidelity: omitted causes/events/answers/reactions and interrupted
actual cut edges. Keep source ASR/context and all initial observations. Do not ask
that request for is_story, general story/pacing criteria, three phase proofs or
mechanical repetition of every retained utterance. No new model pass/role.

The native schema retains resolved, required/requested source units, concrete
blocking issues, optional notes, all source joins and actual boundaries. Existing
factual change/retained continuous witness rules remain. Source readiness needs
complete owned safe coverage and no uncertainty/blocking issues. A meaningful
negative edge is needs_review, not a technical model failure. Schema validity
still cannot prove factual truth.

The pure compiler owns physical interval integrity, chronology and actual audio
geometry, never semantic dialogue truth. Native review still names missing speech
dependencies against original ASR; the independent cut-only viewer owns the local
story's comprehension, causality, ending, pacing and complete speech/actions.
The experimental final approval still required both. Its quality evidence exposed
actual source checks separately without fabricating legacy story proofs.

The experiment preserved absent/v1/v2 readers and bound exact v3 identity through
analysis/case/scoped compiler/qualification inputs. One grounded source restoration
OR blind trim retained existing geometry and fresh-check guards. New failures
could not trigger a second editorial attempt.

## Validation and rollback

Keep default v2 until predeclared v3 replays of the same defective124-observation
case and its54.00s fall-restored timeline with unchanged other gaps pass factual inspection. A correct status
based on an invented event fails acceptance. Mechanism tests must protect legacy
readers, actual references/coverage, dependency uncertainty, shared repair budget
and mandatory independent viewer. Preserve all real negative results; do not
repeat the same paid question until it approves. Default rollback never rewrites
historical responses. Full-route, listening and corpus quality remain required.

## Result

The mechanism suite passed211tests/153subtests, but fixed real controls failed
semantic specificity. At temp/source-fidelity-controls-7d037bd8c411, the SAME
defective edit/124observations was rejected in15.691s and the fall-restored54.00s
edit/121observations was also rejected in13.564s. The latter response invented an
object/action in another gap and attributed speech to an actually silent source
unit. A correct negative status on the known defect cannot compensate for these
incorrect factual claims. No default switch, new proposer, repair loop or output
publication occurred. Warm repeats took3.446/3.399s with0new model calls and remote
transport/local startup forbidden.

The experimental production branches and their tests were removed after archiving
the exact code under that trial's experimental-code directory. Raw questions,
answers, actual plans and measurements remain. The associated diagnostic scripts
are historical and require that archived implementation; do not rerun them against
current v2 code. Task separation remains a design hypothesis, not a demonstrated
quality fix. Further work needs a better source-fact verification approach rather
than accumulating dormant policies or repeating prompts until approval.
