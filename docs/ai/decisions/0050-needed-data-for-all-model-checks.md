# ADR-0050: Needed source evidence for every existing check

Status: accepted. Date: 2026-10-14. Extends ADR-0048; supersedes ADR-0049's expanded retry behavior.

## Decision

Every mode applies target eligibility and source-local payload selection. Economy additionally disables optional check types; enabling them does not permit position, silence or importance alone to trigger another inspection. Targets are actual units/boundaries with concrete uncertainty, omission proposals, detected production/title markers, unresolved roles or user complaints. Whole actual units and source words remain intact.

Initial scene understanding establishes missing source ownership once. Initial structure, dialogue and compact episode mapping construct missing relations. Correctness/export validators run locally and do not themselves upload an episode.

| Existing family | Dispatch and allowed source context |
| --- | --- |
| Semantic boundaries | Ambiguous candidate, nearby frames and complete local speech; bounded uncertainty recovery. |
| Scene understanding/recovery | Missing CURRENT evidence; neighbor images only for missing visual/transition context, adjacent speech for speech/context conflict. |
| Story choice / omission confirmation | Missing selection; confirmation contains omissions, immediate continuity and an earlier retained witness. Repack tiles with original frame IDs; unknown geometry remains unresolved. |
| Credits / titles | Concrete OP/ED/title marker plus nearby region; no source-edge/silence-only rescan. Sparse title groups stay separate. |
| Production sequences | Candidate once; follow-ups contain endpoints/anchors or disputed exceptions and witnesses. Unseen revised boundaries cannot authorize deletion. |
| Source roles / confirmation | Suspicious/unresolved units and source-time neighbors. Independent confirmation rebuilds proposed-unit media only. |
| Closing novelty | Concrete ending/title/closing suspicion, target-only images, at most four relevant prior facts. Unchecked ranges survive. |
| Global visual correction | Actual uncertainty/conflict/recovery; importance and bridge labels alone are insufficient. |
| Selection adjudication | Unresolved CURRENT views; nearest adjacent utterance for spoken meaning, AFTER images for missing visual context/conflict, old descriptions for actual conflict only. |
| Initial episode story map | Compact IDs/summaries/kind/importance, without transcript/images/provenance. No repeated identical whole-map domain retry. |
| Structure / dialogue | Missing accepted ownership mapping with bounded context; duplicate text uses references, full local nodes validate outputs. Relevant memory/registry only. |
| Pacing / silent sequences | Unproven/suspected material; accepted positive unique source proof bypasses recheck. No unrelated earlier dialogue. |
| Endings | Actual unverified plan boundary first, nearby alternatives sequentially; exact reply context and independent >=.9 confirmation. Stop when proof is used. |
| Framing | Local retained temporal strip/current phrase; single-frame fallback only on uncertainty. |
| Final quality recovery | Explicit owners/ranges/transition witnesses; no automatic whole-episode rebuild. |
| User review | Bounded request/part catalogue and nearest positioned utterances. Operation IDs stay local; actual repair independently inspects source. |
| Cover metadata | Matching accepted cache or extractive fallback in economy; full-mode request limited to retained part. |

Filtered-list adjacency is not source adjacency. Dispatch annotates exact regions, filters whole intersecting units, validates unchanged ownership and merges into untouched owners. A long parent touching five seconds cannot silently send unrelated remaining units.

`request_payload` shares wire compaction across LocalVision, DeepSeek and Antigravity, including batch children. Canonical questions, full schemas, accepted keys and original providers remain immutable. JSON/source rejection keeps the compact packet. DeepSeek validates full schemas and checks older exact response keys. Wider accepted adjudication contracts can be read for free and revalidated against CURRENT, retaining original keys instead of being stored as new answers. Diagnostics add byte/page counts and purpose, not token/cost estimates.

## Compatibility, limits and rollback

Completed broader passes remain useful accepted work. For the owned cancelled job, audit original keys/input chains, output hashes, source SHA/ASR/shots/profile, boards and accepted contracts before migrating completed outputs. Preserve original key/context/producer/completion time and audit hash, native reply banks and unresolved fields. No automatic code-mismatch adoption is introduced.

Native APIs cannot safely merge a repaired semantic boundary or changed proof into every cross-owner structure/dialogue relationship. Such cases remain explicitly unresolved instead of triggering whole-episode recovery or manufacturing acceptance. Independent omission/boundary/selection validators remain mandatory. More source can legitimately be needed when all actual owners lack proof.

Offline capture tests check sent text/media, zero-call skips, source-proof rejection, provider caches and serial/batch equivalence. Continuation replay blocks HTTP/model starts and stops at the first missing response. Baselines/backups live under workspace `scratch`; roll back this task's deltas with Studio idle.
