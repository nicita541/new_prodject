# Natural story arcs, bounded continuity and semantic cache identities

## Decision

Build natural arcs from supplied phases, factual state/topic continuity, direct causal links and independently verified complete endings before selecting material or grouping Shorts. Unsupported legacy events remain separate uncertain arc candidates rather than one indivisible episode. Candidate cost measures actual retained source ranges. The preferred part count is a soft objective; a worse semantic cut cannot force an extra part.

Both planners share `story_structure.resolve_continuity`. A dependency is a contextual signal, never authority for transitive whole-scene retention. Every final selected transition compares location, character state, objects, relationship and topic. Chronological evidenced action paths can add multiple individually bounded bridges, such as binding and entering a car. Without action evidence, a direct prerequisite receives uncertain bounded endpoint context with explicit limitations. Unknown states remain unknown; partial units cannot inherit unobserved parent endpoint states.

Ordinary context is bounded to 3–7 seconds and actual word-safe source intervals. A selected question and its immediate source response receive any missing complete reply even without a model dependency. A reply exceeding the ordinary bridge cap is an explicit bounded exception. Confirmed source exclusions and pure credits cannot become context. Added context does not trigger recursive dependency restoration. Part boundaries protect retained words, complete immediate question/answer exchanges, actual action units and supplied protected causal/reaction/payoff ranges before considering a cliffhanger label.

`planner_audit` records candidate scores/reasons, arcs, exact context ranges and proof limitations, every selected transition, boundary rejection reasons and alternative part counts. Its decisions partition the complete original source timeline, including omitted tails and short excluded gaps. These artifacts answer why any retained or omitted interval was chosen without another model request.

`semantic_identity` fingerprints an explicit component/module map: shot detector, semantic detector, grouping, source visual features, storyboard, local prompt, recovery, global story, episode profile, story refinement, pacing, planner and endings. Identities include versions, source policy hashes, literal hashes and actual loaded prompt/policy values. Static AST inspection reproduces literal values without importing model/runtime components or evaluating calls. Runtime credentials/configuration are outside this identity. Relevant nested checkpoints validate their own identities and actual image/source/provider/transcript evidence; the outer analysis and plan identities include the complete signature.

The diagnostic catalog exists even when recovery has no work. Timeline records distinguish cache reuse, fresh analysis, errors and fallbacks. Analysis summaries retain initial and post-recovery uncertainty separately from final global corrections and keep durations after each selection level. A final-event digest protects cached intermediate metrics; only absent duration fields are restored, so fresh stage results win. A corrupt optional diagnostic summary is reported and rebuilt without rejecting valid analysis.

## Compatibility and rollback

Analysis version 12 and planner version 14 replace older derived decisions. Source media, factual ASR and list-of-shot/source-range contracts remain compatible; metadata is additive. Prompt changes invalidate semantic results even without a version bump. Source-policy hashing deliberately favors conservative recomputation over silent stale reuse.

Revert this stage's implementation and completion commits together to restore the former planner policy; keep source and ASR artifacts. Recompute derived plans under the restored component signatures rather than editing cached decisions. No automatic production-provider requests or environment installation are required by the change.

## Validation and limits

Long 1,440-second synthetic fixtures cover the ten required scenarios, genuine retention pressure, five complete arcs versus six preferred parts, incorrect local understanding, bounded dependencies and silent actions. Additional tests cover actual nested-cache invalidation, word safety, full source audit coverage, confirmed exclusions, question/answer preservation under quota and diagnostic cache reuse. Real FFmpeg tests verify source-frame evidence and rendering compatibility; the final run counts are recorded in the implementation report.

Scene/profile confidence remains heuristic rather than calibrated probability. Continuity requires factual supplied states/actions or records uncertainty; endpoint context cannot prove an unobserved action. Unknown legacy scenes use explicit fallback arcs. No complete real episode has been reviewed with production vision models as part of this implementation, so editorial quality on actual episodes still requires visual acceptance.
