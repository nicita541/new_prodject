# Проверка и отправка тестовых отчётов

1. Переключитесь на ветку `fix/montage-stability` и выполните `git pull`.
2. Запустите `ПРОВЕРИТЬ_ПРОЕКТ.bat` двойным щелчком.
3. Тесты Python, React и проверка FFmpeg выводят итоговый статус PASS/FAIL/SKIP.
4. Подробные логи остаются в `temp/verification-reports/<ID>`. Краткий отчёт и очищенные, ограниченные по длине выдержки журналов публикуются в отдельной ветке `test-reports` в каталоге `runs/<ID>`.
5. Для полного набора тестов запустите `ПРОВЕРИТЬ_ПРОЕКТ.bat -Full`. Для запуска без публикации — `ПРОВЕРИТЬ_ПРОЕКТ.bat -NoUpload`.

Нужны Git с настроенным `origin` и авторизацией с правом записи, Python, npm с установленными зависимостями `frontend/node_modules` и portable FFmpeg. Отсутствующие компоненты маркируются SKIP, а не PASS. При ошибке публикации отчёт сохраняется локально. Скрипт не меняет кодовую ветку и не загружает исходные серии или видео.

**Конфиденциальность:** несмотря на отсечение известных форматов токенов и путей, выдержки логов потенциально могут содержать имена файлов и другую частную информацию. Отправка осуществляется в приватный репозиторий, но перед запуском следует убедиться, что тесты не работают с чувствительными материалами. Полные необработанные логи в GitHub не отправляются.
