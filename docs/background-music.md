# Фоновая музыка для Shorts

Поддержка фоновой музыки при финальной сборке Shorts. Музыка подмешивается
к оригинальному звуку видео через существующий FFmpeg-пайплайн
(`app/media.py::render_part`), отдельный конвертер не используется.

## Как это устроено

- Папка с треками: `music/`.
- Конфигурация: `music/config.json` (секция `music`).
- Логика загрузки конфига и выбора трека: `app/music.py`.
- Микс: `app/media.py::render_part` добавляет трек как дополнительный вход
  (`-stream_loop -1`), обрезает/зацикливает его до длительности Shorts,
  применяет `volume`, `afade` (fade in/out) и микширует с голосом через
  `amix`. После микса `alimiter` защищает итог от клиппинга.

## Настройка

`music/config.json`:

```json
{
  "music": {
    "enabled": true,
    "volume": 0.15,
    "fade_in": true,
    "fade_out": true
  }
}
```

| Ключ | Тип | Описание |
|---|---|---|
| `enabled` | bool | Включить/выключить фоновую музыку |
| `volume` | число 0..1 | Громкость музыки (`0.15` = 15%) |
| `fade_in` | bool | Плавное появление в начале |
| `fade_out` | bool | Плавное затухание в конце |

Если файла `config.json` нет, используются значения по умолчанию:
`enabled=true`, `volume=0.15`, `fade_in=true`, `fade_out=true`.

## Изменение громкости

Измените `volume` в `music/config.json`. Голос видео при этом **не меняется**;
меняется только громкость подмешанной музыки.

```json
{ "music": { "volume": 0.25 } }
```

Музыка всегда микшируется как приоритетно тише голоса: голос остаётся на
полной громкости, а лимитер (`alimiter=level=false:limit=0.95`) не даёт
суммарному сигналу превысить норму.

## Отключение

```json
{ "music": { "enabled": false } }
```

Либо просто оставьте папку `music/` пустой — сборка продолжится без музыки,
в лог будет записано, что музыка пропущена.

## Добавление своих треков

1. Положите файл `mp3` / `wav` (или `m4a`, `aac`, `flac`, `ogg`, `opus`)
   в папку `music/`.
2. Убедитесь, что `enabled: true`.
3. Запустите сборку.

Если треков несколько — выбирается случайный. Выбранный трек, громкость,
длительность и флаги loop/fade записываются в лог:

```
Background music:
track=A_Distant_Call.mp3
volume=15%
duration=180.0s
loop=true
fade_in=true
fade_out=true
```
