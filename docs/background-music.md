# Фоновая музыка для Shorts

Поддержка фоновой музыки при финальной сборке Shorts. Музыка подмешивается
к оригинальному звуку видео через существующий FFmpeg-пайплайн
(`app/media.py::render_part`), отдельный конвертер не используется.

## Как это устроено

- Папка с треками: `music/`.
- Конфигурация по умолчанию: `music/config.json` (секция `music`).
  Настройки, сохранённые в интерфейсе, лежат в `data/settings/music.json`
  и имеют приоритет над `music/config.json`.
- Логика загрузки конфига и выбора трека: `app/music.py`.
- Микс: `app/media.py::render_part` добавляет трек как дополнительный вход
  (`-stream_loop -1`), обрезает/зацикливает его до длительности Shorts,
  применяет `volume`, `afade` (fade in/out) и микширует с голосом через
  `amix`. После микса `alimiter` защищает итог от клиппинга.

## Настройка

`music/config.json`:

```json
{
  "music": {
    "enabled": true,
    "volume": 0.15,
    "fade_in": true,
    "fade_out": true
  }
}
```

| Ключ | Тип | Описание |
|---|---|---|
| `enabled` | bool | Включить/выключить фоновую музыку |
| `volume` | число 0..1 | Громкость музыки (`0.15` = 15%) |
| `fade_in` | bool | Плавное появление в начале |
| `fade_out` | bool | Плавное затухание в конце |
| `track` | строка или null | Конкретный трек (для режима `single`); `null` = случайный |
| `mode` | строка | Режим: `random_per_part` (случайный для каждого фрагмента), `single` (один на всё), `per_part` (по фрагментам) |
| `part_tracks` | объект | Соответствие номера части и трека при `mode=per_part` |

Если файла `config.json` нет, используются значения по умолчанию:
`enabled=true`, `volume=0.15`, `mode=random_per_part`, `fade_in=true`, `fade_out=true`.

## Управление через интерфейс

На экране настроек серии есть раздел «Фоновая музыка»:

- переключатель Вкл/Выкл;
- кнопка «📁 Открыть папку с музыкой» — открывает `music/` в проводнике Windows;
- кнопка «🔄 Обновить треки» — перечитывает файлы из папки без перезапуска сервера;
- ползунок громкости 0–100% (по умолчанию 15%);
- выбор режима:
  - **Случайный трек для каждого фрагмента** — каждый шортс получает отдельный случайный трек из папки;
  - **Один общий трек на всю серию** — выбор одного трека или случайного для всех частей;
  - **Выбрать свой трек для каждого фрагмента** — индивидуальное назначение трека (или «Без музыки») для каждого шортса;
- статус текущей конфигурации;
- на экране проверки шортсов для каждой части отображается бейдж с используемым треком.

Изменения сохраняются автоматически в `data/settings/music.json` (этот файл
не отслеживается git) и применяются к следующим сборкам.

## Изменение громкости

Измените громкость ползунком в интерфейсе или параметром `volume`.
Голос видео при этом **не меняется**; меняется только громкость подмешанной музыки.

```json
{ "music": { "volume": 0.25 } }
```

Музыка всегда микшируется как приоритетно тише голоса: голос остаётся на
полной громкости, а лимитер (`alimiter=level=false:limit=0.95`) не даёт
суммарному сигналу превысить норму.

## Отключение

Выключите переключатель в разделе «Фоновая музыка», либо задайте:

```json
{ "music": { "enabled": false } }
```

Либо просто оставьте папку `music/` пустой — сборка продолжится без музыки,
в лог будет записано, что музыка пропущена.

## Добавление своих треков

1. Положите файл `mp3` / `wav` (или `m4a`, `aac`, `flac`, `ogg`, `opus`)
   в папку `music/` (кнопка «Папка музыки» откроет её).
2. Убедитесь, что музыка включена.
3. Выберите трек в интерфейсе (или оставьте «Случайный трек»).
4. Запустите сборку.

Если треков несколько — выбирается случайный. Выбранный трек, громкость,
длительность и флаги loop/fade записываются в лог:

```
Background music:
track=A_Distant_Call.mp3
volume=15%
duration=180.0s
loop=true
fade_in=true
fade_out=true
```
