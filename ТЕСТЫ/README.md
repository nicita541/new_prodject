# ТЕСТЫ — KADR Studio

В этой папке два BAT-файла. Каждый запускается двойным щелчком.

**1_ПРОВЕРКА_БЕЗ_ИИ.bat** — полный технический прогон: Python,
React, сборка, lint, FFmpeg и реальный трёхминутный тест видео, музыки,
субтитров, кэша и API. **Нейросети не запускаются.** Смысловые решения
здесь являются тестовым сценарием.

**2_ПОЛНАЯ_ПРОВЕРКА_С_ИИ.bat** — те же технические проверки, затем реальный
анализ через локальные ASR/Whisper и VLM. При запуске откроется выбор
видео со звуком. Из серии длиннее 3 минут автоматически будет создан
отдельный 180-секундный фрагмент. Оригинал не изменяется.

Чтобы проверять сюжетный участок после вступления:

```powershell
& ".\ТЕСТЫ\2_ПОЛНАЯ_ПРОВЕРКА_С_ИИ.bat" -RealSource "F:\new_prodject\data\imports\episode.mp4" -StartSeconds 300
```

Для настоящего полного теста нельзя подменять ASR готовым
`-RealTranscript`. Отсутствующие локальные модели, ошибка анализа или
отмена выбора видео приводят к **FAIL**, а не к фиктивному успеху.

Оба BAT автоматически отправляют очищенные отчёты в отдельную ветку
**`test-reports`**, не изменяя `codex/dramatic-montage` и `main`.
Сам видеофайл, полный транскрипт и сырые логи реальных моделей не
отправляются. Полные диагностические логи остаются локально в
`logs\tests\<run_id>`, а итог — в
`temp\verification-reports\<run_id>`.

После завершения можно попросить ChatGPT проверить последний отчёт
в GitHub. Полную проверку моделей нужно один раз фактически запустить
на Windows-ПК, где установлены модели и находится исходная серия.

Дополнительная документация: `docs/test-reports.md`.

**Полный тест с ИИ ограничен 30 минутами суммарно**, включая технические
тесты и все этапы обработки. Тайм-аут означает FAIL и сохранение отчёта;
он не означает успешный анализ.


**Автоматические логи ИИ:** после любого полного запуска, включая FAIL и TIMEOUT, программа отправляет безопасный файл ai_diagnostics.json в ветку test-reports. Данные об ошибках, времени, количестве сцен и запросов доступны в GitHub без ручного копирования. Видео, реплики, промпты и ответы модели остаются только на ПК.


**3_ОТПРАВИТЬ_ПОСЛЕДНИЕ_ЛОГИ_ИИ.bat** — однократно досылает безопасный ai_diagnostics.json из уже завершённого (в том числе упавшего) запуска ИИ. Не запускает модели и не повторяет тест. Для следующих полных тестов эта отправка автоматическая; третья кнопка нужна только для старых отчётов.


**Подробная длительность всех этапов:** после запуска появятся `stage_timings.md` и `stage_timings.json` в `test-reports/runs/<id>/`. Там время Python, React, FFmpeg и всех доступных стадий анализа, запросов нейросети и рендеринга. Старые запуски можно дослать третьим BAT без повторной обработки. Вложенные этапы не суммируются — один входит в другой.
