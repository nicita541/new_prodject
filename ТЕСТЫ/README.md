# Проверки KADR Studio

В этой папке **ровно три BAT-файла**. Других экспериментальных запускателей
(Flash, Budget, Fast 4B) здесь больше нет.

| Файл | Что проверяет | Модели | Оплата DeepSeek |
| --- | --- | --- | --- |
| `1_ПРОВЕРКА_БЕЗ_ИИ.bat` | Все Python/Studio тесты, FFmpeg, 180-секундный технический E2E, кэш, субтитры, API | Без запуска ASR/VLM; решения в техническом E2E — тестовый сценарий | Нет |
| `2_ПОЛНАЯ_ПРОВЕРКА_С_ИИ.bat` | Всё выше + реальное исходное видео, распознавание речи, анализ сюжета, проверка качества, экспорт и повторное использование кэша | Локальные Whisper, Qwen 4B и сюжетная Qwen 9B | Нет |
| `3_ПОЛНАЯ_ПРОВЕРКА_DEEPSEEK.bat` | Тот же полный реальный прогон | Whisper/Qwen 4B для аудио/визуальных сцен; DeepSeek Flash для сюжета, темпа и кадрирования, Qwen 4B при ошибке API | Да, без лимита денег/вызовов со стороны KADR |

Все BAT открывают выбор исходного видео, когда нужен реальный ИИ. Для
длинного видео берётся отдельный 180-секундный фрагмент — оригинал не
изменяется. Разрешается выбрать начало:

```powershell
& ".\ТЕСТЫ\3_ПОЛНАЯ_ПРОВЕРКА_DEEPSEEK.bat" -RealSource "F:\new_prodject\data\imports\episode.mp4" -StartSeconds 300
```

DeepSeek использует **уже сохранённый ключ**. Перед платной проверкой
скрипт отдельно предупреждает, что стоимость не ограничена программой,
и требует ввести `UNLIMITED`. Это подтверждение передачи кадров/текста
и обращения к платному API, **не ограничитель количества запросов**.
Повторный запрос к локальному кэшу полных ответов бесплатен; контекстный
кэш самого DeepSeek оплачивается по тарифу провайдера. Если API недоступен,
KADR может переключиться на локальную Qwen 4B, и это видно в диагностике.

**Длительность:** для полноценных проверок установлен общий
технический тайм-аут 2200 секунд (36 минут 40 секунд), включая Python,
Studio и видео. Он никак не относится к деньгам. Если проверка превысила
время, результат — FAIL/TIMEOUT, а не успешное завершение.

Всё автоматически публикует **безопасный отчёт** в ветку `test-reports`:
`checks.json`, `ai_diagnostics.json`, `stage_timings.json`,
`stage_timings.md`, `e2e_overview.json`. Там есть временные затраты
по стадиям, токены, распределение локальных и облачных вызовов, кэш
и реальные ошибки. Вложенные стадии нельзя складывать.

Видео, реплики, исходные кадры, промпты, ключи API и сырые журналы
не публикуются. Они остаются в локальных папках
`temp\verification-reports\<run_id>` и `logs\tests\<run_id>`.

Для **повторной отправки ранее созданного отчёта** отдельный BAT не нужен:
можно вручную запустить
`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish_latest_ai_diagnostics.ps1`.
Новые тесты отправляют диагностику автоматически.

Подробности: `docs/test-reports.md`.
