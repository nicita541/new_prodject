# Проверки KADR Studio

Здесь два BAT-файла для запуска двойным щелчком.

## 1_ПРОВЕРКА_БЕЗ_ИИ.bat

Проверяет **всё техническое**: Python-тесты, React, TypeScript-сборку,
ESLint, FFmpeg/FFprobe и настоящий трёхминутный технический видео-конвейер
(экспорт, субтитры, музыка, кэш, повторный рендер, API).

**Whisper/VLM/DeepSeek НЕ запускаются.** Видеоряд создаётся автоматически,
решения по сценам заранее подготовлены. Это не проверка качества ИИ.

## 2_ПОЛНАЯ_ПРОВЕРКА_С_ИИ.bat

Запускает те же технические проверки и дополнительно **настоящий локальный
анализ** реального трёхминутного фрагмента через ASR/Whisper и VLM.
Никакого заранее заданного результата смыслового анализа здесь нет.

При двойном щелчке откроется диалог выбора **реального сюжетного видео со
звуком**. Подходит также длинная серия: будет извлечено **первых 180 секунд**
в отдельную временную папку (оригинал останется нетронутым).
Желательно выбирать сюжетную часть с русскими репликами, а не опенинг или титры.

Для начала с другой позиции можно запустить через PowerShell:

```powershell
& ".\ТЕСТЫ\2_ПОЛНАЯ_ПРОВЕРКА_С_ИИ.bat" -RealSource "F:\new_prodject\data\imports\episode.mp4" -StartSeconds 300
```

Если не выбрать файл, или модель/контроль качества не сработают, тест
завершится **FAIL** и опубликует отчёт об ошибке. Необходимо, чтобы
локальные модели были заранее установлены и настроены.

## Отчёты автоматически публикуются

Оба BAT-файла без дополнительных аргументов запускают **публикацию** в
`test-reports/runs/<run_id>/` отдельного Git-репозитория. Рабочие ветки
`main` и `codex/dramatic-montage` не засоряются, коммиты с кодом не
делаются. Публикуются только очищенные сводки и короткие фрагменты логов;
**видео, полный транскрипт, модельные промпты и API-ключи не публикуются**.

Локально остаются полные диагностические данные:
`F:\new_prodject\logs\tests\<run_id>` и
`F:\new_prodject\temp\verification-reports\<run_id>`.
После завершения просто напиши в ChatGPT «Тесты завершились, проверяй».

Время проверки с локальной моделью может быть значительным.
Не закрывай окно BAT, пока анализ не завершился.

## Для разработчика

Скрипты находятся в `scripts/verify_project.ps1` и
`scripts/full_pipeline_3min.py`. Параметр `-Quick` оставлен для быстрого
диагностического запуска из консоли или CI; кнопка «без ИИ» **не Quick** —
она выполняет все технические тесты. Публикацию можно временно выключить
лишь явным `-NoUpload` для отладки.
